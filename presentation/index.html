15
01 · code → graph

Functions, not files.

Language adapters parse the repo: Go via go/ast, Java, Svelte split by function. Each node gets a layer. Each edge is a call, a data read or write, or a literal.

logicdatavisualtestsecret

Resources like .vault-secrets.json and fields like Config.HMACSecret are labelled secret.

16
02 · graph diff + guard analysis

A check that runs in
fewer cases.

base · runs on every entry
if strings.HasPrefix(e.Name(), ".") {
    continue
}
head · only when there is no filter
if match != "" {
    if ok, _ := filepath.Match(match, e.Name()); !ok {
        continue
    }
} else if strings.HasPrefix(e.Name(), ".") {
    continue
}

Base and head become two graphs. Each changed node comes with its callers' lines, its diff, and its consumers' lines, down to the frontend fetch() of a Go route.

Conditions with early exits are matched across commits. Same condition, more in front of it:

kind: "narrowed"
added: match == ""
17
03 · routing · reasons()

Four rules decide what
isn't the model's call.

  1. 01A narrowed check next to a secret
  2. 02Changed lines that read or write a secret
  3. 03Fewer calls to an auth function
  4. 04Security code, by name

Anything that matches goes to a named owner from owners.json, with the lines that show why. Everything else merges on evidence.

It once wrote a test
